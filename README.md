# Simulador de fila

Simulador da fila de espera de psicologia em uma UBS. Mostra quantos atendimentos por semana cada psicólogo precisa fazer para zerar a fila, a partir das entradas por mês, das sessões por paciente e do prazo desejado.

Aviso: a conta não considera horários de triagem.

Abra a página publicada no GitHub Pages deste repositório.
